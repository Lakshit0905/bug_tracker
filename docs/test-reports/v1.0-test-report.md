## 6. Known limitations (accepted for v1.0)

- The visual-regression baselines are tied to platform and browser (Linux + Google Chrome here). The project runs on demand; regenerate with `npm run test:visual -- -u` on the CI image.
- In this sandbox, Playwright used the installed Chrome (`CHROME_PATH`) with video off. CI installs Playwright's Chromium and keeps video.
- Docker images and the CI pipeline arrive in Phase 12; this campaign ran on the host.
- Rate limiting is per process (documented; Redis for multi-replica deployments).
