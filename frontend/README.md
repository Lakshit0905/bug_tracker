# BugTrackr — Frontend

React 19 + TypeScript + Vite + Tailwind CSS 4. See [`../docs/08-frontend.md`](../docs/08-frontend.md) for the design system, architecture and decisions.

```bash
npm install
npm run dev        # http://localhost:5173 (needs the backend on :8000)
npm run typecheck
npm run lint
npm run build
```
